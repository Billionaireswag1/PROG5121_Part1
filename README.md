# PROG5121 Part 1

## Description

A Java console application that allows a user to register an account
and then log in using their registered username and password.

## Features

- Username validation
- Password complexity validation
- South African cell phone number validation
- User registration
- User login
- Login status messages
- JUnit unit testing
